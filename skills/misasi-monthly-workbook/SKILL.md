# MISASI 한달기록 워크북 — 매월 25일 자동 회고록

한 달 동안 monthly-reflection 스킬이 노션 "한달기록" DB에 쌓아온 일별 기록(사실·핵심감정·욕구·
깨달음·부탁)을 모아, 아래 MISASI 워크북 형식 그대로 한 편의 월간 회고록을 자동으로 초안 작성하고
"한달회고록" DB에 저장한다.

> 한달기록은 나를 평가하기 위함이 아니라, 나를 이해하기 위한 도구다.
> 이 워크북은 한 달의 기록을 통해 '나다움'을 발견하고, 삶의 태도를 정리하며,
> 미래의 방향과 기여로 확장하기 위해 설계되었다.

## 🔧 실행 순서

### STEP 1. 이번 달 기록 수집
- notion-query-data-sources(SQL 모드)로 "한달기록" data source에서 이번 달 1일 ~ 25일(또는 오늘까지)
  범위의 모든 행을 `date:날짜:start` 기준으로 조회한다.
- 가져온 각 행에서 `날짜, 있었던 일, 핵심감정, 욕구, 깨달음, 부탁`을 모두 확보한다.
- 기록이 5건 미만이면(한 달을 판단하기엔 데이터가 적으면) 사용자에게 "이번 달은 기록이 O건뿐이에요.
  그래도 진행할까요?"라고 한 번만 확인한다.

### STEP 2. 패턴 분석 (섹션별 재료 준비)
수집한 데이터를 아래처럼 정리해 각 섹션의 재료로 쓴다. 모든 결론은 실제 기록에 근거해야 하며,
기록에 없는 내용을 지어내지 않는다.

- **M(ME) 재료** — `있었던 일`·`깨달음`에서 반복적으로 드러나는 행동/역할/장면을 모은다.
- **I(INSIDE) 재료** — `핵심감정`을 전부 모아 빈도 집계 → 가장 많이 등장한 감정 top 2~3.
  같은 방식으로 `욕구`도 빈도 집계 → 가장 자주 나타난 욕구 top 2~3.
- **S(STYLE) 재료** — `있었던 일`(문제 상황) 옆의 `부탁`·`깨달음`을 나란히 보며, 문제 앞에서
  반복적으로 선택한 대응 방식(예: 일단 해본다 / 정리부터 한다 / 도움을 요청한다)을 찾는다.
- **A(ANCHOR) 재료** — 여러 날 반복해서 등장하는 욕구·가치 단어 중, 힘들 때도 포기하지 않고
  지켜낸 것으로 보이는 것을 고른다.
- **S(STEP) 재료** — `부탁`으로 제안됐던 행동이 이후 날짜의 `있었던 일`에 실제로 나타났는지 확인해,
  실천으로 이어진 것을 찾는다. (이어졌는지 불확실하면 "시도"로만 표현)
- **I(IMPACT) 재료** — 위 M~S 다섯 재료를 종합해, 이 흐름이 이어졌을 때의 자연스러운 확장을 그린다.

### STEP 3. 워크북 초안 작성
아래 [워크북 포맷]에 맞춰 전체를 한 번에 초안으로 작성한다. 섹션마다 되묻지 않고, 전체를
완성해서 한 번에 보여준다. 각 문장 끝의 "출처"에는 근거가 된 날짜를 구체적으로 적는다
(예: `출처: 7/3, 7/12, 7/19 기록`).

### STEP 4. 결과 제시 + 가벼운 확인 (한 번만)
- 완성된 워크북 전체를 보여준다.
- 마지막에 한 번만 확인한다: "혹시 다르게 느껴지는 문장이 있으면 알려주세요. 없으면 이대로 저장할게요!"
- 수정 요청이 오면 해당 문장만 반영하고, 전체를 다시 만들지 않는다.

### STEP 5. 노션에 저장
- [한달회고록] data source에 새 페이지를 만든다 (notion-create-pages).
- 속성 매핑:
  - `제목`: `YYYY년 M월 한달회고록`
  - `월`: 이번 달 1일 (YYYY-MM-01)
  - `이번달의 나(M)` / `마음이 원한 것(I)` / `선택한 태도(S)` / `지킨 가치(A)` / `성장 습관(S)` / `확장 자산(I)`: 각 섹션의 빈칸 채우기 문장
  - `다음달에게 한 문장`: 마무리 질문의 두 번째 답
- 페이지 본문(content)에는 [워크북 포맷] 전체(질문 + 기록 공간 + 문장 + 출처 포함)를 그대로 담는다.
- 저장 후 "🌱 이번 달 한달회고록을 저장했어요"처럼 짧게 알려주고 마무리한다.

## ✍️ 작성 원칙

1. **기록에 없는 것을 지어내지 않기** — 모든 문장은 실제 노션 기록에 근거하고, 근거 날짜를 출처로 남긴다
2. **평가하지 않기** — 워크북 취지대로, 잘했다/못했다 평가가 아니라 있는 그대로의 패턴 발견으로 쓴다
3. **질문 문구는 그대로** — MISASI 워크북의 질문 문구를 임의로 바꾸지 않는다
4. **짧고 선명하게** — 빈칸 채우기 문장은 장황하지 않게, 한 단어~한 구절로
5. **되묻지 않기** — 전체 초안을 한 번에 완성해서 보여주고, 확인은 끝에 한 번만

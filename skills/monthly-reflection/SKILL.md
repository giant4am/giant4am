# 한달기록 — 10분 자동 성찰 기록 스킬

매일 밤, 사용자는 **오늘 있었던 일(사실)** 하나만 적는다. 나머지 네 단계
**핵심감정 3가지 → 욕구 → 깨달음 → 부탁**은 스킬이 자동으로 채워 한 편의 성찰 기록을
완성하고, 완성된 기록은 **노션 "한달기록" 데이터베이스에 그날의 새 항목으로 자동 저장**된다.
이 기록이 하루하루 쌓이면 미사시 "나의 한달 기록 챌린지"의 한 달치 기록이 된다.

**목표: 부담 없이 10분 안에 끝낸다.** 사용자에게 여러 번 묻지 않는다.

## 🔧 실행 순서

### STEP 1. 사실 받기
- 질문: "오늘 있었던 일을 편하게 적어주세요. 판단이나 해석 없이, 있었던 그대로만요. 여러 개여도 괜찮아요."
- 사용자가 감정을 섞어서 말해도 괜찮다 — 이후 스킬이 사실과 감정을 분리해 알아서 활용한다.
- 사실이 너무 짧거나 모호하면(예: "그냥 그랬어") 딱 한 번만 부드럽게 되물어 구체적인 장면을 얻는다. 그 이상 캐묻지 않는다.

### STEP 2. 핵심감정 3가지 자동 추출
- 사용자가 적은 사실 속 표현(직접 감정 단어 + 상황에서 드러나는 뉘앙스)을 함께 분석한다.
- 아래 [감정 단어 참고 리스트]를 기준으로 삼아, 가장 강하게 느껴졌을 감정을 **최대 3가지**로 추린다.
  - 사실에 없는 감정을 임의로 지어내지 않는다 — 항상 사용자가 적은 문장에 근거를 둔다.
  - 비슷한 감정어가 겹치면(예: "속상한"·"서운한") 대표 단어 하나로 통합한다.
  - 사건이 여러 개면 감정도 사건마다 다를 수 있다 — 그중 가장 두드러지는 3개만 남긴다.
  - 감정마다 근거가 된 사실 문장을 내부적으로 짚어두고 STEP 3~5에 활용한다.

### STEP 3. 욕구 자동 매칭
- 각 핵심감정을 아래 [감정 → 욕구 연결 가이드]에 따라 욕구로 치환한다.
- 여러 감정이 비슷한 욕구로 수렴되면 욕구도 통합해 1~2개로 정리한다. 억지로 3개를 채우지 않는다.

### STEP 4. 깨달음 자동 생성
- 사실 + 감정 + 욕구를 하나로 엮어, 오늘 하루에서 얻을 수 있는 알아차림을 1~2문장으로 만든다.
- 권장 형식: "오늘 나는 [사실] 때문에 [감정]을 느꼈고, 그건 내 안에 [욕구]가 있었기 때문이었다. [한 걸음 더 나아간 알아차림]."
- 훈계나 정답처럼 쓰지 않는다. 사용자 1인칭 시점의 자기 발견 문장으로 쓴다.

### STEP 5. 부탁 자동 생성
- STEP 3에서 찾은 욕구를 **오늘 또는 가까운 시일 안에 충족시킬 수 있는 구체적 행동**으로 바꿔 부탁 문장을 만든다.
- 원칙:
  - **구체적으로** — "잘 챙기기" (X) → "자기 전에 내일 할 일 3가지 적어두기" (O)
  - **긍정형 행동언어로** — "~하지 않기" 대신 "~하기"
  - **바로 실행 가능한 크기로** — 오늘~내일 안에 해볼 수 있는 작은 행동 단위
  - 대상은 나 자신일 수도, 타인일 수도 있음
- 욕구가 2개 이상이면 부탁도 욕구별로 하나씩, 최대 2개까지 제안한다.

### STEP 6. 결과 제시 + 가벼운 확인 (한 번만)
- [완성된 기록 포맷]으로 정리해서 바로 보여준다.
- 마지막에 딱 한 번만 확인한다: "혹시 다르게 느끼신 부분이 있으면 알려주세요. 없으면 이대로 완료할게요!"
- 수정 요청이 오면 해당 부분만 빠르게 반영하고, 전체를 처음부터 다시 묻지 않는다.
- 별다른 피드백이 없으면 그대로 최종본으로 확정한다.

### STEP 7. 노션에 저장
- 확정되면 바로 [노션 데이터베이스]에 오늘 날짜의 새 페이지로 추가한다 (notion-create-pages, parent는 위 data source ID).
- 속성 매핑:
  - `제목`: `M/D (요일) 한달기록` (예: `7/23 (목) 한달기록`)
  - `날짜`: 오늘 날짜 (YYYY-MM-DD)
  - `있었던 일`: STEP 1에서 정리한 사실
  - `핵심감정`: STEP 2에서 뽑은 감정 단어 배열 (최대 3개)
  - `욕구`: STEP 3에서 매칭한 욕구 배열 (1~2개)
  - `깨달음`: STEP 4 문장
  - `부탁`: STEP 5 문장. 2개면 줄바꿈으로 구분해 한 필드에 담는다
- 저장이 끝나면 "🗂️ 노션 한달기록에 저장했어요"처럼 짧게 알려주고 마무리한다. 저장 성공 여부를 사용자에게 다시 확인받지 않는다.
- 같은 날짜의 기록이 이미 있으면(재실행 등) 새로 만들지 않고 기존 페이지를 덮어쓰도록(update) 확인 후 처리한다.

## ✍️ 자동 생성 원칙

1. **사실에 없는 것을 지어내지 않기** — 감정·욕구·깨달음은 항상 사용자가 적은 사실에 근거
2. **판단하지 않기** — 어떤 사실·감정·욕구도 옳고 그름으로 평가하지 않는다
3. **되묻지 않기** — 단계마다 확인받지 않고, 끝에 한 번만 가볍게 확인한다
4. **따뜻하게** — 지시가 아닌 동반자의 말투, 설교 없이
5. **실행 가능하게** — 부탁은 항상 오늘~내일 안에 해볼 수 있는 크기로

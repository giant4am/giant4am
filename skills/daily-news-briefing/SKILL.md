# 매일 뉴스 브리핑

매일 아침, 5개 고정 분야의 최신 뉴스를 웹에서 검색해 **딱 5개 항목**으로 요약한다.
읽는 사람은 성장과 노후준비에 관심이 많은 중년이며, 이 표 하나만 읽으면 오늘 하루 뉴스
파악이 끝나야 하고, 손대지 않고 5분 안에 그대로 쓸 수 있어야 한다.

---

## 📌 실행 시점

- 매일 **오전 5시 (한국시간 KST)** 자동 실행
- 사용자가 "오늘의 뉴스", "뉴스 브리핑" 등을 언급하면 언제든 즉시 실행

---

## 📥 입력물

- 사용자가 따로 입력할 것은 없다 — 아래 [검색 분야] 5개를 매번 고정으로 검색한다.
- 로그인이 필요한 사내 시스템·유료 구독 자료는 쓰지 않는다. **공개 웹 뉴스만** 검색한다(WebSearch).

---

## 🔧 실행 순서

### STEP 1. 5개 분야 검색 (AI는 필수)
아래 5개 분야에서 각각 최신 뉴스를 웹 검색한다. AI 분야는 매일 반드시 포함한다.

1. 🤖 AI 관련 뉴스 (필수)
2. 🏛️ 우리나라 정책 관련 뉴스
3. 💰 경제·투자 뉴스
4. 🌿 웰니스·노후 뉴스
5. 🌍 국내외 트렌드 뉴스

분야마다 후보 기사를 여러 개 찾는다 (최소 2~3개씩).

### STEP 2. 선별
- 홍보성 기사(보도자료 재탕, 특정 상품·서비스 광고성 기사)와 중복 기사(같은 사건을 다룬
  여러 매체 기사)는 제외한다.
- 남은 후보 중, **성장과 노후준비에 관심이 많은 중년 독자**에게 의미 있는 순서로 우선순위를 매긴다.
- 분야마다 가장 중요한 기사 **딱 1건**을 골라 최종 5건(=5개 분야 × 1건)을 확정한다.

### STEP 3. 항목 정리 (3줄 형식)
선별된 기사마다 아래 세 요소를 3줄 이내로 정리한다.
1. **무슨 일** — 사실 위주, 개조식(단어 나열) 금지, 완결된 문장으로
2. **출처** — 매체명 (+가능하면 날짜)
3. **우리에게 주는 의미** — 이 기사가 중년 독자의 성장·노후준비에 어떤 시사점을 주는지

### STEP 4. 표로 정리해 화면에 표시
[출력 형식]에 맞춰 마크다운 표로 만들어 채팅 화면에 바로 보여준다. 별도 저장·전송은 하지 않는다.

---

## ✅ 출력 형식

```
| 분야 | 제목 | 요약 | 출처 | 시사점 |
|---|---|---|---|---|
| 🤖 AI | [기사 제목] | [무슨 일 — 1문장] | [매체명, 날짜] | [중년 독자에게 주는 의미 — 1~2문장] |
| 🏛️ 정책 | ... | ... | ... | ... |
| 💰 경제투자 | ... | ... | ... | ... |
| 🌿 웰니스노후 | ... | ... | ... | ... |
| 🌍 국내외트렌드 | ... | ... | ... | ... |
```

- 표 위에 한 줄로 오늘 날짜와 "매일 뉴스 브리핑"이라는 제목을 붙인다. 예: `📰 2026-07-27 (월) 매일 뉴스 브리핑`
- 표 아래에 "미확인" 또는 "중요도 애매" 표시가 하나라도 있으면 그 의미를 한 줄로 짧게 설명한다 (없으면 생략).

---

## 🚫 규칙

1. **개조식 금지** — 요약·시사점은 단어 나열이 아니라 완결된 문장으로 쓴다.
2. **항목당 3줄 이내** — 요약+시사점을 합쳐 장황하게 늘어놓지 않는다. 간결하게.
3. **출처 없는 추측을 단정하지 않는다** — 기사에서 확인되지 않은 내용(전망·추측성 서술 등)은
   단정형 문장으로 쓰지 않고, 확인 안 된 사실은 해당 셀에 **"미확인"**이라고 표시한다.
4. **애매하면 일단 포함** — 오늘 이 분야에 뚜렷하게 중요한 기사가 없어 애매하면, 그래도
   가장 근접한 기사를 포함하되 시사점 칸 앞에 **"(중요도 애매)"**라고 표시한다. 임의로 빼지 않는다.

- [ ] 표 형태(제목|요약|출처|시사점 포함)로 화면에 바로 표시했는가?
